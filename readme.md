# 🎮 Computação Gráfica e Tecnologias Imersivas
Repositório criado para adicionar todos os projetos feitos em aula, da matéria Computação Gráfica e Tecnologias Imersivas, do Centro Universitário Mater Dei - UNIMATER

# 🛠️ Como executar os projetos
Para rodar os projetos localmente, você precisará ter o Python instalado e seguir os passos abaixo no seu terminal:
1. Clone o repositório
2. Crie um ambiente virtual
```Bash
python -m venv venv
```
3. Ative o ambiente virtual
```Bash
source venv/Scripts/activate
```
4. Instale as dependências
```Bash
pip install pygame
```
